# Spec: Native Ngrok Integration

## Overview
Replace the external dependency on standalone `cloudflared` or `ngrok` binaries with the native `ngrok-go` library. This will allow the application to programmatically create a public tunnel to the local HTTP file server, which is required for the Instagram Graph API to access local media files during the publishing process.

## Functional Requirements
- **Embedded Tunneling:** Integrate `ngrok-go` to establish a secure tunnel directly from within the Go application.
- **Automatic Lifecycle:** The tunnel should automatically start when the application launches (if an auth token is available) and terminate when the application exits.
- **Secure Credential Management:**
    - Provide a UI field in the "Settings" view for users to enter their Ngrok Auth Token.
    - Store the token securely using the OS keychain via `go-keyring`.
- **Dynamic Configuration:** Use the URL generated by `ngrok-go` as the base URL for media files sent to the Instagram API.
- **Status Visibility:** Display the current tunnel status (Active/Inactive) and the public URL in the TUI Dashboard.

## Non-Functional Requirements
- **Error Handling:** Gracefully handle cases where the tunnel fails to start (e.g., invalid token, no internet) by notifying the user through the TUI.
- **Zero Binary Dependency:** Ensure no external tunnel binaries are required in the user's `$PATH`.

## Acceptance Criteria
- [ ] Users can enter an Ngrok token in the Settings menu.
- [ ] The token is persisted securely across restarts.
- [ ] Upon startup, the app successfully starts an ngrok tunnel.
- [ ] The generated public URL is correctly used to create Instagram media containers.
- [ ] The app closes the tunnel cleanly on exit.

## Out of Scope
- Support for other tunneling providers (Cloudflare, SSH) in this track.
- Support for static ngrok domains (fixed URLs) for free-tier users.
